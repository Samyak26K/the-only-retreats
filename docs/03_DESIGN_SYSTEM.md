# Design Philosophy

The design system is inspired by:

• Himalayan landscapes
• Handmade paper
• Morning mist
• Stone monasteries
• Cedar wood
• Wool
• Brass
• Editorial magazines
• Slow living
• Nature

The interface should never compete with the content.

It should quietly support storytelling.

Semantic HTML.

Screen reader friendly.

# Performance Rules

Use Next/Image.

Lazy load below fold.

Avoid heavy videos.

Prefer CSS animations.

Only use GSAP where storytelling benefits.

# Design Principle

Every page should feel like opening a beautifully printed Himalayan journal.

The interface should disappear.

The story should remain.
